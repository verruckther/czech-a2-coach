# Czech A2 Coach

## Project Overview

Czech A2 Coach is an AI-powered personal Czech tutor designed to help English-speaking learners prepare for the Czech A2 language examination required for permanent residence in the Czech Republic.

The goal is to provide personalized lessons, clear grammar explanations, practical exercises, feedback, and realistic exam practice.

## Core Features

- Initial assessment of Czech proficiency
- Personalized learning plan
- Adaptive daily lessons
- Grammar and vocabulary explanations
- Reading practice
- Listening practice
- Writing correction and feedback
- Speaking practice
- Tracking of recurring mistakes and weaknesses
- Mock exams based on official exam formats
- Progress tracking

## Knowledge Sources

### 1. Official Exam Materials
The official examination materials determine exam requirements, task formats, timing, scoring, and assessment criteria.

Official website: https://cestina-pro-cizince.cz/trvaly-pobyt/en/

### 2. Czech Teaching Materials
Textbooks and learning resources support grammar explanations, vocabulary, language exercises, and the development of Czech proficiency.

### 3. Supplementary Resources
Resources such as Mozaika and Speak Czech / CzechOnline may support everyday Czech, additional practice, and listening.

## Source Priority Rules

1. Official exam materials take priority for exam requirements and scoring.
2. Textbooks and teaching resources support language instruction.
3. Supplementary resources provide additional examples and practice.
4. AI-generated exercises must be original and aligned with the appropriate exam task format.
5. The AI must not invent official requirements or present AI practice scores as official exam results.

## Teaching Method

The learning cycle is:

**Understand → Practice → Remember → Use Naturally**

When correcting a mistake, the tutor should:
1. Show the learner's mistake.
2. Provide a corrected sentence.
3. Explain the relevant grammar or language rule.
4. Give simple examples.
5. Provide targeted practice.
6. Track recurring weaknesses for future lessons.

## Development Approach

The project will be developed in stages:

1. Collect and classify learning resources.
2. Create the textbook and teaching source map.
3. Organize the knowledge base.
4. Define the AI tutor's instructions and teaching behavior.
5. Build a working prototype.
6. Test and improve the tutor.

## Important Limitations

Czech A2 Coach is an independent learning project. It is not an official examination authority and cannot guarantee that a learner will pass the examination.

Copyrighted materials will only be stored or redistributed when permitted.
